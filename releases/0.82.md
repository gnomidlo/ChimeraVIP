# ChimeraVIP 0.82 — Characters

Dodano pełnoprawny moduł `src/features/characters.lua` do rejestrowania odmian postaci, relacji i kolorowania nazw.

## Najważniejsze zmiany

- wynik `odmien <imie>` zapisuje sześć przypadków postaci w `ChimeraVIP-data/characters.lua`,
- świeżo dodana postać jest **nieprzypisana**, zamiast automatycznie neutralnej,
- relacje pozostają trzema znaczącymi grupami: `przyjaciele`, `neutralni`, `wrogowie`,
- skróty grup: `p`, `n`, `w`, a `?`/`brak` usuwa przypisanie,
- `highlight_enabled` jest oddzielony od stanu całego modułu,
- każda postać ma własne `highlight = true/false`,
- moduł jest przełączalny przez `/cvip ustawienia modul postacie on|off`,
- panel `/cvip ustawienia` pokazuje osobny przełącznik `POST`,
- `/postacie on|off` steruje wyłącznie globalnym kolorowaniem nazw.

## Wydajność

Moduł nie przeszukuje już całej bazy i wszystkich odmian przy każdym trafieniu triggera. Po wczytaniu lub zmianie bazy budowane są:

- `form_index` — odwrotny indeks `odmiana -> postać`,
- `highlight_entries` — gotowa, posortowana lista odmian przeznaczonych do kolorowania.

Cache jest przebudowywany tylko po zmianie danych postaci, relacji lub ustawienia highlightu.

## Unicode

Sortowanie długości nazw korzysta z `utf8.len()` tam, gdzie jest dostępne. Przed `selectSection()` bajtowy indeks Lua jest przeliczany na pozycję znakową, co zabezpiecza kolorowanie przy wcześniejszych znakach UTF-8 w linii.

## API dla innych modułów

```lua
chimera_vip.characters:get("Fartaillah", "biernik")
chimera_vip.characters:get("Fartaillaha", "celownik")
```

Wyszukiwanie działa po mianowniku i wszystkich zapisanych odmianach.

## Komendy

```text
/postacie
/postacie przyjaciele|neutralni|wrogowie|nieprzypisani
/postacie szukaj <tekst>
/postacie grupa <imie> p|n|w|?
/postacie highlight <imie> on|off
/postacie info <imie>
/postacie kolor <grupa> <0-255|#RRGGBB>
/postacie usun <imie>
/postacie on|off
/postacie pomoc
```
