# ChimeraVIP 0.111

- Jeden timer kontrolek po reloadzie; niezmienione przyciski nie są odrysowywane.
- Defense Tracker wiąże kolor i obronę z linią bufora, zamiast odrzucać wszystkie trafienia przez 100 ms po obronie. Kolejność ANSI/regex i pełny tekst mają testy regresji; potrzebny jest jeszcze test w żywym Mudlecie.
- Auto-wsparcie ponawia komendę tylko przy nadal aktualnym celu i lokacji. Reload oraz rozłączenie anulują oczekującą próbę.
- Updater pobiera manifest i pliki z jednego commita, sprawdza Git blob SHA oraz składnię Lua. Rollback przy błędzie zapisu obejmuje pliki i metadane; timeout i osobne ścieżki prób izolują spóźnione odpowiedzi.
- Adapter GMCP dla lokacji, drużyny i walki; inicjalizacja rdzenia bez oficjalnego UI. Interfejs nadal korzysta z oficjalnych struktur.
- Diagnostyka brakujących zależności i błędów modułów. Błąd startu istniejącej instalacji nie rozpoczyna ponownej instalacji.
- Testy Lua 5.1 runtime i aktualizatora dodane do CI.

Po przejściu ze starszej wersji zalecany jest restart profilu: timerów osieroconych wcześniej przez 0.110 nie da się usunąć po utracie ich identyfikatorów. Pierwsza instalacja nadal używa dotychczasowego instalatora; przypięcie commita i weryfikacja zawartości dotyczą updatera 0.111.
