# ChimeraVIP 0.81 — Defense semantics fix

Naprawiono klasyfikację obron w Defense Trackerze.

Kolor `otrzymane_*` nie oznacza już automatycznie trafienia. Integracja z Combat Colors najpierw analizuje treść linii i rozpoznaje udaną obronę, nawet gdy komunikat zaczyna się pełnym opisem ataku.

Obsługiwane są m.in. rzeczywiste warianty:

```text
... w ciebie, lecz tobie udaje sie zbic je z lini ataku jednorecznym krasnoludzkim mlotem.
... w ciebie, lecz tobie udaje sie oslonic zdobionym ciemnym puklerzem.
```

Rozpoznawane są:
- zasłona (`block`) wraz z nazwą tarczy/puklerza,
- parowanie / zbicie z linii ataku (`parry`) wraz z nazwą broni,
- unik,
- pudło,
- zatrzymanie pancerzem.

Dopiero linia `otrzymane_*`, która nie zawiera żadnego rozpoznanego komunikatu obronnego, jest liczona jako trafienie.

Parser obsługuje oba szyki tekstu parowania (`udaje sie zbic je` oraz starszy `udaje je zbic`) oraz `lini/linii ataku`.
