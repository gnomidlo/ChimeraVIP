# ChimeraVIP 0.79 — Defense Report Alignment

Poprawka formatowania raportów Defense Trackera.

`string.format("%-Ns")` liczy szerokość tekstu bajtami, przez co polskie znaki UTF-8 (`ł`, `ś`, `ó`, `ę` itd.) przesuwały kolumny w `/def` i `/def sprzet`.

Od 0.79 Defense Tracker używa własnego dopełniania opartego na `utf8.len()`, z fallbackiem do długości bajtowej, jeśli API UTF-8 nie jest dostępne.

Poprawiono wyrównanie:
- nagłówka `Znane próby ataku`,
- wszystkich wierszy `/def`,
- nazw wyposażenia w `/def sprzet`.

Logika liczenia statystyk nie została zmieniona.
