# ChimeraVIP 0.113

- Podsumowanie oceny sprzętu jest domykane z krótkim opóźnieniem, aby odebrać opcjonalną końcową linię o zaklętej magii.
- Wykrycie linii `Sadzac po ... zostala zakleta jakas magia.` natychmiast wyświetla podsumowanie z oznaczeniem `| MAGIA`.
- Zwykłe przedmioty nadal otrzymują podsumowanie automatycznie, bez oznaczenia magii.
- Dodano ochronę przed powieleniem podsumowania przez spóźniony timer.
- Dodano test pełnej oceny magicznego tasaka, w tym stanu 7/7 oraz parametrów WYW i SKUT.
