# ChimeraVIP 0.101

## Updater 2.0 i walidacja wydan

- Manifest v2 zachowuje kompatybilna liste `files`, ale dodaje `schema = 2`, `file_meta` z Git blob SHA i rozmiarem oraz `remove`.
- Aktualizacja z 0.100 do 0.101 korzysta jeszcze ze starego updatera i pobierze komplet plikow. Po zainstalowaniu 0.101 kolejne wersje beda porownywane z lokalnym `installed_manifest.lua` i pobierane beda tylko zmienione pliki.
- Nowy updater sprawdza rozmiar pobranych plikow przed instalacja.
- Zmienione i usuwane pliki sa backupowane przed podmiana. Blad w trakcie instalacji uruchamia rollback kodu.
- `remove` oficjalnie sprzata stare pliki; pierwszym wpisem jest historyczny `src/features/progression.lua`.
- Dodano `.github/workflows/release-check.yml` uruchamiajacy `tools/release_check.lua` na pushach do `main` i pull requestach.
- Release checker sprawdza zgodnosc VERSION/manifest/bootstrap, skladnie Lua, komplet metadanych, rozmiary plikow, Git blob SHA, duplikaty i liste `remove`.

Nie zmienia to komend ani funkcji widocznych podczas gry poza komunikatami aktualizatora.
