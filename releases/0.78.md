# ChimeraVIP 0.78 — Defense Tracker

Nowy sesyjny moduł statystyk defensywy.

## Zasada działania

Defense Tracker działa wyłącznie w pamięci bieżącej sesji Mudleta. Nie zapisuje statystyk na dysku i nie tworzy historii między restartami.

Liczone są:

- pudła przeciwników,
- uniki,
- parowania,
- zasłony,
- ciosy całkowicie zatrzymane pancerzem,
- znane trafienia `otrzymane_brak/niskie/srednie/wysokie` przekazane przez Combat Colors.

`OBRONIONE` oznacza sumę: pudło + unik + parowanie + zasłona. Pancerz jest raportowany osobno.

## Sprzęt

Udane zasłony, parowania i zatrzymania pancerzem są rozbijane według dokładnej nazwy przedmiotu z komunikatu gry. Pozwala to porównywać udział poszczególnych tarcz/puklerzy, broni i elementów pancerza w udanych obronach.

Raport nie nazywa tego skutecznością ani AC, ponieważ bez informacji o liczbie nieudanych prób dla konkretnego przedmiotu nie znamy właściwego mianownika.

## Komendy

```text
/def
/def sprzet
/def last [N]
/def reset
/def help
```

## Trafienia i Combat Colors

Combat Colors podnosi nowy event `chimeraVipIncomingHit` dla rozpoznanych kategorii `otrzymane_*`. Defense Tracker słucha tego eventu zamiast tworzyć drugi komplet triggerów ANSI.

Jeżeli `otrzymane_brak = -1`, trafienia 0/3 nie mają koloru i na obecnym etapie nie są w pełni rozpoznawalne. `/def` jawnie informuje wtedy, że procenty obejmują tylko znane próby ataku.

Po zebraniu przykładowych tekstów skutecznych trafień należących do `otrzymane_brak` można rozszerzyć parser bez zmiany architektury modułu.

## Event

Każde rozpoznane zdarzenie obrony podnosi:

```text
chimeraVipDefenseEvent
```

z typem zdarzenia, szczegółem i bieżącym stanem sesji.
