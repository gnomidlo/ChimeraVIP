# ChimeraVIP 0.71 — instalacja, integracja i pomoc

Wersja 0.71 porządkuje sposób wdrażania ChimeraVIP i przygotowuje nakładkę dla osób, które nie znają jeszcze jej modułów.

## Najważniejsze zmiany

### Instalacja jedną komendą

ChimeraVIP można teraz zainstalować jako pakiet Mudleta:

```lua
lua installPackage("https://raw.githubusercontent.com/gnomidlo/ChimeraVIP/main/packages/ChimeraVIP.xml")
```

Pakiet instaluje trwały skrypt `ChimeraVIP/loader`. Loader pobiera aktualną wersję runtime z GitHuba i przechowuje ją w `getMudletHomeDir()/ChimeraVIP/`.

Od tej wersji `loader.lua` znajduje się również w manifeście aktualizacji.

### Oficjalne gags

Po uruchomieniu ChimeraVIP warstwa integracyjna wyłącza folder skryptów:

```text
chimera/skrypty/ui/gags
```

Oficjalny kod nie jest edytowany ani usuwany — folder jest wyłącznie dezaktywowany przez API Mudleta.

### Pełna pomoc `/cvip`

`/cvip` stało się głównym centrum pomocy. Opisuje:

- interfejs i Quiet Footer,
- auto-wsparcie,
- tracker XP,
- cechy,
- progres postaci,
- integrację z oficjalną Chimerą,
- aktualizacje i pliki użytkownika.

Dostępne są również wybrane sekcje:

```text
/cvip pomoc xp
/cvip pomoc progres
/cvip pomoc ui
```

Status wersji został przeniesiony do:

```text
/cvip status
```

## Aktualizacja z 0.70

```text
/cvip sprawdz
/cvip aktualizuj
```

Po aktualizacji kolejne wersje będą aktualizowały również lokalny `loader.lua`.
