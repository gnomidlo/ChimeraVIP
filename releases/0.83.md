# ChimeraVIP 0.83 — XP rules & modular help

## XP: reguły utrzymywane centralnie

Usunięto lokalne zarządzanie regułami klasyfikacji mobów z modułu XP.

Nie są już dostępne:

```text
/xp add
/xp del
/xp rules
```

Pliki `ChimeraVIP-data/xp_mobs.lua` i starszy `chimera_xp_mobs.lua` nie są już wczytywane przez tracker. Istniejące pliki mogą pozostać na dysku, ale są ignorowane.

Wbudowane wyjątki w 0.83:

```text
krasnolud chaosu <- krasnoluda chaosu
smoczy ogr       <- smoczego ogra
czarny ork       <- czarnego orka
```

Kolejne niestandardowe typy mobów będą dopisywane bezpośrednio do ChimeraVIP.

## Pomoc modułowa

`/cvip` nie drukuje już pełnej dokumentacji wszystkich funkcji. Pokazuje krótki opis ChimeraVIP, listę modułów oraz komendę prowadzącą do pomocy każdego z nich.

Główne wejścia do pomocy:

```text
/ui pomoc
/walka pomoc
/wsparcie pomoc
/def pomoc
/xp pomoc
/cechy pomoc
/progres pomoc
/postacie pomoc
/ustawienia pomoc
```

`/cvip pomoc` pokazuje ten sam krótki indeks. Starsze `/cvip pomoc <sekcja>` pozostaje jako kompatybilny skrót do szczegółowej pomocy sekcji, ale nie jest głównym sposobem nawigacji.
