# ChimeraVIP 0.106

## Sprzet po zmianie silnika Chimery

- parser `oceniasz starannie` korzysta z nowych liczbowych danych,
- oryginalna odpowiedz MUD-a nie jest gagowana ani przebudowywana,
- bron pokazuje WYW, SKUT i ich sume,
- pancerz pokazuje dokladne KP klute/ciete/obuchowe dla kazdej lokalizacji,
- podsumowanie zachowuje stan `[x/y]`, wartosc oraz informacje o zakletej magii,
- nie zakladamy maksymalnej skali nowych parametrow broni, dopoki nie zbierzemy danych z nowego silnika.

Wersja testowa celowo zostawia surowe linie widoczne, aby latwo wylapac nowe warianty odpowiedzi.
